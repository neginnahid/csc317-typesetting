# Typesetting a community school page

CSC 317 assignment. Typesetting and styling for the St Huxley's Community College
homepage, based on the MDN typesetting exercise.

Live page: https://neginnahid.github.io/csc317-typesetting/

All of the styling is in `style.css`, below the
`/* WRITE YOUR styling/typesetting CSS code BELOW HERE */` comment, plus the font
import at the top of that file. `index.html` is unchanged from the version provided.
